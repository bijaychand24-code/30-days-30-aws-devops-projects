# ☁️ Day 01 — AWS EC2 Static Website

## 🎯 Project Overview

This is my Day 1 project of the **30 Days AWS & DevOps Practice Journey**.

In this project, I learned how to launch an AWS EC2 instance, connect to an Ubuntu Linux server using SSH, install Nginx, and deploy a static HTML website.

- Ubuntu Linux
- Nginx
- Git
- GitHub
- HTML
