
# Day 05 — AWS IAM Lab

## Objective
Learn identity and access management in AWS.

## AWS Services
- AWS IAM
- IAM Users
- IAM Groups
- IAM Policies

## Tasks
- Create an IAM user.
- Create an IAM group.
- Add a user to the group.
- Explore IAM policies.
- Understand least-privilege access.

## Key Learnings
IAM controls who can access AWS resources
and what actions they can perform.

Users represent identities.
Groups organize users.
Policies define permissions.

## Security Best Practices
- Follow least privilege.
- Avoid using the root account for daily tasks.
- Never upload credentials or access keys.
- Enable MFA where appropriate.
