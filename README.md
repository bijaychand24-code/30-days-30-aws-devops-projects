# 30 Days — 30 AWS + GitHub Projects

## Overview

A comprehensive 30-day challenge to learn AWS DevOps and GitHub skills through hands-on projects. Each day focuses on specific AWS services and GitHub tools, building from basic concepts to advanced DevOps pipelines.

## Project Structure

This repository uses **one repository for the entire challenge**:

```
30-days-30-aws-devops-projects/
│
├── Day-01-EC2-Static-Website/
├── Day-02-Portfolio-Deployment/
├── Day-03-S3-Static-Website/
├── Day-04-S3-Storage/
├── Day-05-IAM-Lab/
├── Day-06-EC2-Web-Server/
├── Day-07-EC2-Automation/
├── Day-08-Serverless-Contact-Form/
├── Day-09-Lambda-API/
├── Day-10-Serverless-Todo/
│
├── ...
│
├── Day-27-Terraform-AWS/
├── Day-28-Terraform-GitHub-Actions/
├── Day-29-DevOps-Pipeline/
└── Day-30-Final-Project/
└── README.md
```

## Daily Project Format

For **every day**, the structure is consistent:

```
Day-XX-Project/
├── README.md
├── screenshots/
├── src/
├── docker/
└── .github/
```

### Root README.md Format

```
# Day 01 — Deploy Static Website on AWS EC2

## Objective
Deploy a static website using Amazon EC2.

## AWS Services
- EC2
- Security Groups

## Tools
- Linux
- Git
- GitHub
- Nginx

## Architecture
User → Internet → EC2 → Nginx → Website

## Implementation
1. Launch EC2
2. Connect using SSH
3. Install Nginx
4. Clone GitHub repository
5. Configure website
6. Test using public IP

## What I Learned
- EC2 basics
- Linux commands
- SSH
- Nginx
- Git deployment

## Screenshots
Add screenshots here.

## Result
Website successfully deployed on AWS EC2.
```
