# Day 04 - AWS S3 Storage Project

## Objective
Learn cloud storage using Amazon S3.

## AWS Services
- Amazon S3
- AWS IAM

## Tasks
- Create an S3 bucket
- Upload files to S3
- Organize files into folders
- Enable bucket versioning
- Configure secure access

## Security
- Block public access.
- Never upload AWS credentials.

Add screenshots of the S3 bucket and uploaded files.

## Learning Outcome
Learn how to store and manage files securely in AWS S3.
